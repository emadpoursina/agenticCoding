# /learn

Cursor slash entry for the AiNative **learn** skill. Do not invent a parallel workflow.

1. Read `$HOME/.cursor/skills/learn/SKILL.md` and follow it.
2. Also read `AGENTS.md` and `rule.md` in that same folder when they exist.
3. Pass `$ARGUMENTS` as the user request.

This file exists because Cursor slash commands are a separate surface from Agent Skills. OpenCode and Claude Code load the same skill from `~/.config/opencode/skill/learn/` and `~/.claude/skills/learn/`.
