# RTK (Rust Token Killer)

**Date:** 2026-08-15
**Status:** Queued
**Category:** tool

## Hypothesis

RTK is a single-binary CLI proxy that compresses bash output (`git status`, `grep`, `ls`, test runners, linters) before the agent reads it — claimed up to 90% reduction on command output, ~10ms overhead, with an auto-rewrite hook (`git status` → `rtk git status`). If it works, it reduces input-token burn during PIV **Implementation** (scout scanning, git diff reads, test output) without changing agent behavior — relevant to the **Tools** (terminal output filtering) part of the agentic system.

Has an [OpenCode plugin](https://github.com/rtk-ai/rtk#auto-rewrite-hook) (`rtk init -g --opencode`) — directly usable in this repo's harness.

## Source

- https://github.com/rtk-ai/rtk
- Install: `brew install rtk` or `curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh`
- Init: `rtk init -g` (Claude Code) / `rtk init -g --opencode` (OpenCode); savings dashboard: `rtk gain`
