# 9Router

**Date:** 2026-08-15
**Status:** Queued
**Category:** tool

## Hypothesis

9Router routes a single OpenAI-compatible endpoint (`http://localhost:20128/v1`) across 40+ providers with automatic fallback (subscription → cheap → free), quota tracking, multi-account round-robin, and a built-in RTK token saver. If it works, it could cut LLM cost to ~$0 on everyday sessions and stop rate-limit stalls — relevant to the **Tools** (model access) and **Harness** (provider routing) parts of the agentic system, with no change to how agents write prompts.

Claims: ~20-40% input-token savings from built-in RTK compression; free tiers (Kiro ~50 credits/mo, OpenCode Free no-auth, Vertex $300 credits) that fluctuate — verify current availability before relying on them.
