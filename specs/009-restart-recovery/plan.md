## Summary

Phases 0–6 already run one PIV workflow in-process and lose the slot when the process dies. This is Phase 7 from `scratch/implimentation.md` (§50 interrupted execution, §60 Phase 7, §61 reliability): **persist the overlay**, **reclaim one interrupted run** on start-up (resume or safe-restart a whole **phase**), **recover the isolated copy/branch**, and **prevent a second worker** (including a second live copy while the alive signal is fresh). Not Phase 4 check-retry, not Phase 8 E2E.

Technical approach: atomic `overlay.json` + 60s `alive` file under required `execution.overlay_dir`; `become_ready()` before starts; `recover_workspace` (no fetch, dirty allowed, same identities); pytest simulates restart. See [research.md](./research.md).

## Technical Context

**Language/Version**: Python 3.12 (`>=3.12,<3.14`) via uv — already pinned in `personalAgent/pyproject.toml`

**Testing**: pytest + ruff; new `personalAgent/tests/test_restart_recovery.py`; stand-in `ModelService` + `MemoryTaskBoard` + `MemoryGitHost`; injected clock; temp overlay dir + workspace root. Existing 005–008 modules stay green

**Target Platform**: Host pytest (macOS/Linux). Compose volume for overlay dir in production config. Live Docker kill not required for the contract

**Project Type**: Library (in-process orchestrator inside `hermes_kanban`)

**Performance Goals**: One blocking reclaim/start; heartbeat tick ≤ 15s while slot held. No throughput target

**Constraints**: No new third-party libraries. No `$HOME` overlay default. No Resume press. No second PR / extra Phase 4 attempt from crash alone. No `git fetch` on reclaim. No concurrent workers. No dedicated `restarted` Telegram event. Methodology read-only

**Scale/Scope**: One V0 slot, one overlay document, recover path on workspace manager, start-up gate. Production `projects: []` unchanged

## Implementation notes (for `/speckit-tasks`, not this command)

- `from_config` requires `execution.overlay_dir` and calls `become_ready`.
- Atomic `os.replace` only; last complete snapshot is truth.
- Alive TTL 60s; tick while slot held; tests inject `clock`.
- Reclaim grain = whole phase; crash does not bump `attempt` / `publish_attempt`.
- `recover_workspace`, never `prepare_workspace`, on reclaim.
- No fetch on recover; local copy wins; missing both → `BLOCKED`.
- `SlotHeldError` vs `WorkflowBusyError` (process vs slot).
- No new Telegram kind. `task_start` occurrence stays unique per `run_id`.
- Compose volume for `/var/lib/hermes-kanban`; pytest uses `tmp_path`.
- Stop after restart-recovery contract checks; do not start Phase 8.
