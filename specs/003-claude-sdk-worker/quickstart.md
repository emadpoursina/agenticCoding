# Quickstart: validating the Claude SDK worker harness

Runnable checks after implementation. No live Anthropic job is required for the gate below (authenticated `claude -p` is optional extra). Run from repository root.

## Prerequisites

- Git worktree for this feature (`specs/003-claude-sdk-worker`)
- `node`, `rg`, `bash`
- Do **not** `npm install @anthropic-ai/claude-agent-sdk` or `pip install claude-agent-sdk` for these checks

## 1. Wrapper self-test (AC-1, AC-4, AC-5, AC-6, AC-9, AC-10)

```bash
node AiNative/docs/agents/claude-harness/claude-spawn.mjs --self-test
```

**Pass**: prints `SELFTEST: ok`. Covers STATUS regex, timeout parse, edit vs scout argv, always `-p`, no `--bare` default, no skip-permissions / `bypassPermissions`, contract append flag, stream-json reconstruct, missing `--model` exit 2, required-flag fail-closed helper, SIGINT-first timeout fields.

## 2. Parent still wrapper-only (AC-2)

```bash

  AiNative/docs/agents/speckit-orchestrate/SKILL.md \
  AiNative/docs/agents/claude-harness/SKILL.md
```

**Pass**: spawn instructions name the wrapper. Skills tell the parent not to exec `claude -p` itself.

## 3. Ready selftests (AC-3, AC-8, FR-014, FR-015)
